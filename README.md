# Скрипт для обновления цен активов в эксель таблице
Вайбкодинг, питон
<h1>Описание работы скрипта</h1>
Скрипт при активации запрашивает открытие файла, в котором необходимо провести обновление цен активов через API из двух источников:<br>
1. Мосбиржа;<br>
2. COINGECKO;<br><br>
После выбора файла, он автоматически получает цены, с задержкой в 15 минут, на акции и ОФЗ с мосбиржи, и на криптовалюту с COINGECKO, записывает эти данные в столбец D листа Data.<br><br>
Дополнительно оставляет 2 артефакта:<br>
1) Запись последней даты обновления на листе Dashboard в ячейке C1 в формате DD.MM.YYYY HH.MM.SS;<br>
2) Цену доллара на прошлый день из JSON файла с сайта ЦБ РФ.
<h1>Как скрипт считывает активы?</h1>
Скрипт считывает цены активов по тикерам:<br>
1) Акции - Тикер с Московской биржи (SBER, LKOH и так далее);
2) ОФЗ - по названию для пользователей (ОФЗ 25025 и так далее);
3) Криптовалюту – по короткому и полному названию игнорируя регистр (BTC, bitcoin, Bitcoin - для скрипта одно и то же).
